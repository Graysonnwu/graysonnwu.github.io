# 焦散光路 / Caustic Layout

在三维场景中摆放光源、透镜和投影图，预览轮廓、阴影与曲面。
Arrange a light source, lens and projection image in 3D, with outline, shadow and surface previews.

- [中文](https://graysonnwu.github.io/caustic_layout/?lang=zh) · [English](https://graysonnwu.github.io/caustic_layout/?lang=en)
- 撤销左侧的 EN / 中文按钮切换语言。Use EN / 中文 next to Undo to switch languages.
- 点击物体调整参数，拖动空白处旋转视角，双指缩放和平移。Select an object to edit it; drag empty space to orbit, or use two fingers to pan and zoom.
- 调整图像中可拖动四角、旋转、反相及调整亮度曲线。Adjust image combines corner warping, rotation, inversion and tone curves.
- 导出项目即可保存或分享，重新导入可继续编辑。Export to save or share; import the file to continue editing.
- 手机浏览器可调用系统文件分享；可用的应用由系统决定。Supported mobile browsers can open the system share sheet; available apps depend on the device.
- 图片在浏览器本地处理。Images are processed locally in your browser.

这是布置工具，曲面预览是粗略估计。制造前需完成详细设计和验证。
This is a layout tool. The surface preview is an estimate; detailed design and validation are needed before manufacturing.
